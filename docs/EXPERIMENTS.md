# 实验设计与结果

本文档记录 2026-10 的一轮系统性升级：把论文中写死的调制公式改造成可消融的
机制族，补上统计检验与可复现性，并回答三个论文悬而未决的问题——

1. α = 0.5 是好选择吗？最优能好到哪去？
2. 方向一致性项（`sign(r)·s`）真的在起作用吗？
3. "调制优于特征拼接"这个核心论点，实跑对比后还成立吗？

**结论先行**：三个答案分别是"不是、上界也不显著"、"是（去掉它显著变差）"、
"成立（拼接更差），但调制自身的改善不显著"。

## 1. 实验设置

| 项目 | 取值 | 与论文的关系 |
|---|---|---|
| 数据 | 2026-02-27 → 2026-04-30，45 个交易日 × 16 只股票 | 论文只用了前 22 个交易日 |
| 训练 | 每个验证日独立重训（截至当日数据），window=20, hidden=64, 2 层, 200 epoch | 与论文一致 |
| 种子 | 固定 seed=0，python/numpy/torch 三处同步 | 论文未固定，不可复现 |
| 基线 | 同一 LSTM 在同一验证日的纯价格预测 | 与论文一致 |
| 改善量 | `improvement = MAE_base − MAE_cand`，正值 = 调制更优 | 同论文 `sentiment_improve` |
| 检验 | 逐股改善量的 Wilcoxon 符号秩检验 + bootstrap 95% CI（n=5000） | 论文未做 |

每个 (股票, 验证日) 是一次独立实验：训练只看得到验证日之前的数据，预测验证日
收盘价。共 720 次独立训练。

**关键工程决策**：情绪调制是纯后处理，与 LSTM 训练无关。回测只跑一次并把
原始预测缓存到 `results/predictions.csv`，之后所有机制变体、α 取值、信号变换
都在缓存上重算——换一个设定只要几秒，而不是再训 16 分钟。

## 2. 发现 0：情绪分几乎没有区分度（升级前没发现的根因）

对全部 720 个 (股票, 交易日) 情绪分的分布统计：

```
min −0.994   max +0.997   mean +0.471   std 0.678
> 0.9      : 319 (44.3%)
0.5 ~ 0.9  : 137 (19.0%)
0.0 ~ 0.5  : 123 (17.1%)
−0.5 ~ 0.0 :  28 (3.9%)
< −0.5     : 113 (15.7%)
```

近半样本贴在 +0.9 以上：FinBERT2 二分类在这批新闻标题上高度自信地输出"正面"，
日度均值化之后 `s` 长期接近 +1。后果是调制因子

```
m = 1 + α·sign(r)·s ≈ 1 + α·sign(r)
```

在大多数日子退化为常数 1.5（预测涨时）或 0.5（预测跌时），**失去了逐日区分
能力**。论文把"调制无效"归因于宏观环境，这个信号层面的原因此前没有被指出。

`baff/mechanism.py` 因此把信号变换独立出来：`raw`（论文做法）、`tanh`（压极端
值）、`cs_zscore`（同日横截面标准化，只消除截面内的偏置，不含未来数据）。

## 3. 发现 1：α 扫描——强度越大越差，最优值也不显著

在 sign 机制上扫 α ∈ [0, 1]（`results/ablations/alpha_sweep.csv`）：

| α | 绝对改善/股 | 相对改善/股 | 改善占比 | Wilcoxon p |
|---:|---:|---:|---:|---:|
| 0.0 | 0 | 0 | 0% | — |
| 0.1 | +0.0139 | +0.043% | 62.5% | 0.231 |
| 0.2 | +0.0251 | +0.038% | 56.3% | 0.274 |
| 0.3 | +0.0297 | −0.034% | 56.3% | 0.376 |
| 0.4 | **+0.0301** | −0.205% | 50.0% | 0.495 |
| 0.5（论文） | +0.0260 | −0.487% | 50.0% | 0.597 |
| 0.8 | −0.0327 | −1.911% | 37.5% | 0.706 |
| 1.0 | −0.1158 | −3.356% | 37.5% | 0.528 |

- 全部 α 的 p 值都远大于 0.05，**没有任何强度能达到统计显著**；
- 绝对口径在 α≈0.4 达到峰值 +0.03（约为基线 MAE 的 0.7%），论文的 0.5 恰好
  在峰值附近——但这个"峰值"本身在噪声范围内；
- **绝对与相对口径在 α ≥ 0.3 后方向相反**：绝对 MAE 的"改善"全部来自低价股，
  高价股的相对误差在恶化。只报告绝对口径会得出"α 略调小就能改善"的误导结论。

## 4. 发现 2：方向一致性项是机制里真正必要的部分

把方向项去掉（`magnitude` 机制，`m = 1 + α·s`，情绪强就放大、不管方向对不对）：

| 机制 | 绝对改善/股 | 相对改善/股 | p 值 |
|---|---:|---:|---:|
| sign/raw/α=0.5（论文） | +0.026 | −0.49% | 0.60 |
| **magnitude/raw/α=0.5** | **−0.433** | **−9.36%** | **0.0002** |
| magnitude/raw/α=best | +0.000（最优 α=0） | 0% | — |

不带方向一致性时调制**显著恶化**预测（p < 0.001），而数据驱动的最优 α 收敛到
0——即"别用情绪"。这说明：

- 论文机制里真正干活的是**方向一致性项**，而不是情绪强度本身；
- 情绪分单独作为缩放因子是纯粹的有害噪声（与发现 0 一致：它几乎没有区分度，
  恒正的 s 只会把所有预测往"放大"方向拉）。

`soft`（tanh 连续方向）整体略优于 `sign`（最优变体 +0.041 vs +0.030），方向
正确——给大收益率的预测更高权重是合理的——但差异同样不显著（p = 0.30）。

## 5. 发现 3：特征拼接实跑后确实更差（论文论点首次获得对照支持）

论文第 1.4 节论证了特征级融合的四类缺陷，但全文没有实跑这个对照组。这里把
情绪分作为 LSTM 的第二输入通道（`PriceLSTMConcat`），在完全相同的协议下重训：

| 路线 | 整体 MAE |
|---|---:|
| 行为调制（论文机制，α=0.5） | **4.608** |
| 纯价格基线 | 4.634 |
| 特征拼接（情绪为输入通道） | 4.721 |

排序与论文的论点一致：**调制 > 无情绪 > 拼接**。拼接把情绪硬塞进价格特征空间，
模型要同时学两个量纲的动态，45 天的训练数据撑不起来——这为论文的机制选择
提供了第一个实证依据。但同样注意：三者差距都在 2.5% 以内，不构成显著结论。

## 6. 方向层面：调制没有改善方向判断

| 指标 | 基线 | 调制后 |
|---|---:|---:|
| 方向准确率 | 0.507 | 0.507 |
| IC（Spearman） | 0.033 | 0.048 |
| 情绪分 IC | 0.174 | — |

sign 调制不改变预测符号（除非调制因子为负），方向准确率不变是预期行为。
值得注意的两点：

- 情绪分与真实收益的秩相关有 **0.174**——信号并非纯噪声，弱但为正。调制没能
  把它转化为更好的预测，问题出在机制对信号的使用方式（发现 0），而不是信号
  本身完全无用；
- IC 从 0.033 提升到 0.048，幅度太小不足以下结论。

## 7. 统计口径注意事项（读结果表前必看）

1. **改善量的正负约定**：`improvement = MAE_base − MAE_cand`，正 = 调制更好。
2. **绝对 vs 相对口径**：股票价格从 3 元到 300 元，绝对 MAE 的均值会被高价股
   主导。所有结论都以两个口径互相验证，两者矛盾时（见发现 1 的 α ≥ 0.3）
   以相对口径为准。
3. **多重比较**：机制对比表有 17 个变体，按 0.05 的显著性水平纯 by chance
   也会出现约 1 个 p < 0.05。唯一显著的条目（magnitude/raw 的恶化）方向符合
   先验且幅度大，可信；正改善条目无一显著。
4. **单种子**：全部结果来自 seed=0。`run_backtest.py --seeds 0,1,2` 可以估计
   训练随机性的方差（每个种子约 16 分钟）。

## 8. 复现

```bash
pip install -e ".[torch,dev]"          # torch 装 CPU 版即可
python experiments/run_backtest.py     # ~16 min，产出 results/predictions.csv
python experiments/run_backtest.py --sentiment-input \
    --out results/predictions_concat.csv   # ~16 min，拼接基线
python experiments/run_ablations.py    # ~10 s，纯后处理
pytest tests -q                        # 95 个用例
```

数据：`data/raw/{YYYYMMDD}/`（gitignored），格式见 `data/sample/README.md`。
固定了种子后，`predictions.csv` 可以逐位复现。

## 9. 尚未解决

- 多种子方差估计与更长的验证窗口（数据只到 2026-04-30）；
- 情绪分自身的校准：换个分类阈值、用连续强度而非两概率之差、或按新闻条数
  置信度加权，都可能比在调制机制上做文章收益更大；
- α 的在线学习（本实验的 `fit_alpha` 是离线上界，不含前视偏差的在线版本
  需要扩展窗口设计）。
